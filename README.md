# Binance-Bot
Bot Overview
Your bot implements three trading strategies:

Trend Following: Uses SMA crossovers with ADX confirmation
Range Trading: Uses Bollinger Bands and ATR for trading within price channels
Mean Reversion: Uses RSI to identify overbought/oversold conditions
The enhanced version (enhanced_trading_bot.py) offers significant improvements over the basic version, including multi-pair trading, backtesting, and command-line arguments.
